# CaitlinBannan.com

Website for contra and community folk dance caller Caitlin Bannan.
Used to launch the website [caitlinbannan.com](https://caitlinbannan.com) hosted through 
Netlify and built with Eleventy 
using variations on the Fernfolio template.

## Building the website

- Install the goods: `npm install`
- Run it: `npm start`
- You should now be able to see everything running on localhost:8080

## Credit
* Code was originally taken from [fernfolio-11ty-template](https://github.com/tylerMRoderick/fernfolio-11ty-template).
* AI coding assistance, such as Claude AI was used to update the format to match the needs of showing the gigs and dance choreography.
